# NewLife Hospital Management System

A Hospital Management System built using ASP.NET Core MVC, Entity Framework Core, and SQL Server.

## Features
- Register Patient Membership
- View All Patients
- Update Patient Email
- Cancel Membership

## Technologies Used
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- C#
- Razor Views

## Architecture
- MVC Project
- Class Library (DAL)
- Repository Pattern
- Multi-Layer Architecture
